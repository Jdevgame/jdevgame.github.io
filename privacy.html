Privacy policy

mailhub · last updated October 8, 2026

mailhub is a personal, self-hosted tool. It is used only by its owner, with the owner's own Google accounts. This policy explains what it does with Google user data.

Data accessed

With your permission, mailhub uses the Gmail API with the read-only scope https://www.googleapis.com/auth/gmail.readonly to read your email messages, labels and basic account information (your email address).

How the data is used

Messages are downloaded to, and stored only on, the owner's own device, where they are indexed so the owner can search and read their mail. mailhub never sends, deletes, moves or modifies any email.

Sharing

Google user data is not sold, shared with, or transferred to any third party, and is not sent to any server operated by the developer. It is not used for advertising, and it is not used to develop, improve or train generalized AI or machine-learning models.

Storage, security and deletion

Access tokens and downloaded mail are stored only on the owner's device, with file permissions restricted to the owner. You can revoke mailhub's access at any time at myaccount.google.com/permissions, and removing an account in mailhub also revokes its access. Downloaded mail can be deleted from the device by the owner.

Google API Services User Data Policy

mailhub's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
